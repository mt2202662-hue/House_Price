# Project Report – Kaggle Ames House Price Prediction

## 1. Objective
Build a supervised machine-learning application that estimates a house's sale price from property characteristics and demonstrates a complete predictive workflow.

## 2. Problem type
This is **supervised regression**. `SalePrice` is a continuous numerical target. It is not a classification or clustering project.

## 3. Dataset
The Kaggle Ames Housing competition supplies `train.csv`, `test.csv`, `data_description.txt` and `sample_submission.csv`. The training file contains labelled examples with `SalePrice`; the test file contains feature rows without target labels. `Id` is an identifier and is excluded from model inputs.

## 4. Preprocessing and feature engineering
The training script performs transformations within a scikit-learn Pipeline to prevent preprocessing leakage between folds:

- Numeric missing values: median imputation plus missingness indicators.
- Categorical missing values: a dedicated `Missing` category.
- Categorical features: one-hot encoding, unknown categories ignored, rare categories grouped.
- Numeric features: standard scaling (helpful for Ridge; generally harmless for tree models).
- Added features: total floor area, total bath equivalents, total porch area, age at sale, years since remodel, remodeled flag, quality × living area, garage flag and basement flag.

The original columns are retained alongside the engineered features.

## 5. Models and why they are included

| Model | Role | Reason for inclusion |
|---|---|---|
| DummyRegressor | Baseline | Sets a simple reference score |
| Ridge | Linear baseline | Regularized linear model; useful comparison |
| Random Forest | Bagging ensemble | Learns nonlinear patterns and interactions |
| Extra Trees | Randomized ensemble | Strong tree-based comparison with randomized splits |
| Gradient Boosting | Boosting ensemble | Sequentially corrects previous model errors |

No winner is assumed in advance. The training script selects the model with the lowest mean 5-fold cross-validation RMSLE.

## 6. Validation design
- Reserve 20% of `train.csv` as a holdout validation set.
- Run shuffled 5-fold cross-validation only on the remaining 80% training portion.
- Select a model using mean CV RMSLE.
- Report validation RMSLE, MAE, RMSE and R² on the untouched holdout.
- Refit the selected model on all labelled rows before predicting Kaggle `test.csv`.

The random split is appropriate for a first learning exercise, but it is not a guarantee of future-market generalization.

## 7. Target transform and metrics
The target is transformed with `log1p(SalePrice)` for fitting because the competition uses RMSLE. Predictions are transformed back with `expm1`.

- MAE: average absolute dollar error.
- RMSE: square-root of average squared dollar error.
- R²: coefficient of determination.
- RMSLE: root mean squared logarithmic error; this is the Kaggle competition metric.

Actual metric values are generated by running `python train.py`; they are intentionally not fabricated in this report.

## 8. Deliverables
- EDA reports and plots.
- Model-comparison CSV.
- Holdout validation metrics and predictions.
- Refit model saved as Joblib artifact.
- Kaggle-format `submission.csv`.
- Streamlit application for interactive educational predictions.

## 9. Limitations
Ames is a historical housing dataset. The Streamlit interface exposes selected features while all other features use training-set defaults. It is an educational demonstration and not an appraisal of an actual house.


## 10. Example execution results (prepared run)

The provided project was executed successfully in a Python environment using the included Kaggle files. In this run:

| Model | 5-fold CV RMSLE (mean) | Holdout RMSLE | Holdout MAE (USD) | Holdout RMSE (USD) | Holdout R² |
|---|---:|---:|---:|---:|---:|
| Extra Trees | 0.13446 | 0.14162 | 16,262 | 26,623 | 0.9076 |
| Ridge Regression | 0.14062 | 0.13640 | 16,485 | 26,271 | 0.9100 |
| Random Forest | 0.14127 | 0.14308 | 16,773 | 29,198 | 0.8889 |
| Gradient Boosting | 0.14995 | 0.16557 | 19,859 | 38,382 | 0.8079 |
| Dummy Median Baseline | 0.39048 | 0.43228 | 59,568 | 88,667 | -0.0250 |

Extra Trees was selected because it had the lowest **mean cross-validation RMSLE**. Notice that Ridge achieved a slightly lower RMSLE on this one holdout split. That is useful evidence that model rankings can vary between data splits; the selected model is not guaranteed to be universally best. Compare the CV and holdout results rather than relying on one score.

The Kaggle test set has no public labels in the downloaded files, so its true competition RMSLE cannot be calculated locally. The generated `outputs/submission.csv` has 1,459 predictions and must be uploaded to Kaggle to receive a leaderboard score.
